## Contributing

Thanks for your interest in improving `tx-sim-risk`! Contributions are welcome.

### Development setup
- Node.js 18+ is required
- Install dependencies: `npm ci`
- Run tests: `npm test`
- Lint and typecheck: `npm run lint && npm run typecheck`

### Pull requests
- Keep changes focused and reasonably small
- Include tests for new behavior and edge cases
- Maintain 90%+ line coverage (`npm run test:coverage`)
- Run `npm run format` before pushing

### Commit messages
- Use clear, descriptive subject lines (present tense)
- Group logically related changes into separate commits

### Reporting issues
Please include:
- What you did
- What you expected to happen
- What actually happened (logs, stack traces)
- Minimal reproduction when possible
